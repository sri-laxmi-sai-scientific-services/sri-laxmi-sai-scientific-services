# AP Enterprises website

Responsive static website for AP Enterprises. The website is kept in the `ap-enterprises/` folder of the SLS repository so it does not overwrite the existing Sri Laxmi Sai Scientific Services site.

## Preview locally
Open `index.html` in a browser, or run a local static server from this folder:

```bash
python -m http.server 8000
```

Then open http://localhost:8000.

## Publish with GitHub Pages
The project can be published as a project subsite at:
`https://sri-laxmi-sai-scientific-services.github.io/sri-laxmi-sai-scientific-services/ap-enterprises/`
